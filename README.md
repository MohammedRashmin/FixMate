# 🛠️ FixMate - Subscription-Based Skilled Labor Platform

A modern, responsive marketing website for FixMate, Sri Lanka's premier subscription-based skilled labor platform, designed to match PickMe's professional marketing approach with a focus on subscription services.

## 🌟 Features

### ✨ Subscription-Based Platform Design
- **Professional Header** - Clean header with subscription-focused navigation
- **Subscription CTA** - Prominent subscription call-to-action section
- **Service Icons** - Four main service categories with subscription benefits
- **Achievement Section** - "SUBSCRIPTION BASED PLATFORM" design with service images
- **About & Impact Sections** - Side-by-side layout emphasizing subscription value
- **News Section** - Latest updates with subscription promotions
- **Download Section** - App store buttons with FixMate branding
- **Comprehensive Footer** - Multi-column layout with subscription links

### 💳 Subscription Model Features
- **FixMate Pass** - Premium subscription service with unlimited access
- **Flexible Plans** - Basic, Premium, and Unlimited subscription tiers
- **Cost Savings** - Significant savings compared to pay-per-service
- **Priority Support** - Enhanced customer service for subscribers
- **Unlimited Services** - Access to all skilled labor categories

### 🎯 Service Categories
1. **Skilled Labor** - Plumbers, electricians, mechanics
2. **Home Services** - Day care, cleaning, maintenance
3. **Heavy Work** - Construction, moving, landscaping
4. **Quick Fix** - Emergency repairs and urgent services

### 🚀 Interactive Elements
- **Dropdown Navigation** - Professional menu system
- **Hover Effects** - Smooth animations on all interactive elements
- **Mobile Menu** - Responsive hamburger menu
- **Smooth Scrolling** - Navigation links smoothly scroll to sections
- **Responsive Design** - Works perfectly on all devices

### 📱 Mobile-First Approach
- **Responsive Grid** - Automatically adjusts layout for different screen sizes
- **Touch-Friendly** - Optimized for mobile interactions
- **Mobile Navigation** - Hamburger menu for mobile devices
- **Optimized Typography** - Readable text at all screen sizes

## 🛠️ Technical Stack

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript (ES6+)**: Interactive functionality and animations
- **Font Awesome**: Professional icons

## 🚀 Getting Started

### Option 1: Open Directly
1. Download all files to a folder
2. Double-click `index.html` to open in your browser
3. The website will work immediately with CSS placeholder images

### Option 2: Local Server (Recommended)
1. Install a local server (e.g., Live Server extension in VS Code)
2. Open the project folder
3. Start the local server
4. Navigate to the local URL

### Option 3: Deploy Online
1. Upload all files to your web hosting service
2. Ensure the file structure is maintained
3. The website will work on any modern web server
